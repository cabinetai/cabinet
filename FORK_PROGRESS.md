# Good Place fork progress

[2026-07-24] Created the Good Place distribution line: renamed the Electron app and bundle identity so it can coexist with upstream Cabinet, pointed publishing and auto-updates at `souljorje/cabinet`, prevented fork releases from attempting to publish upstream-owned npm packages, and made unsigned release validation supported. Added an opt-in Electron workspace-sync supervisor that activates only when the selected data repository contains `scripts/cabinet-sync.mjs`; it synchronizes on startup, every 30 seconds, and immediately after Cabinet commits while reusing the repository's existing conflict-safe sync policy. Added unit coverage and distribution documentation.
[2026-07-24] Hardened the packaged Good Place build after mounted-DMG testing: assigned a separate Electron user-data directory, moved `.cabinet.env` credential storage to the selected data directory, skipped Squirrel auto-update checks on read-only installer volumes, and pointed both native and in-app update checks at the fork. Rebuilt the arm64 DMG and verified app health, daemon health, bundle identity, and ad-hoc code signing from the mounted artifact.
[2026-07-24] Prevented the Good Place desktop app from copying bundled starter content into an established Cabinet selected as its data directory. Existing directories with a `.cabinet` manifest are now left untouched; new empty directories still receive the starter content.
[2026-07-24] Kept the packaged Next.js fetch cache in memory so running an installed desktop app cannot write into its signed bundle and invalidate its code signature. Updated the macOS smoke test to launch a writable copy from the DMG and verify its signature again after shutdown.
[2026-07-25] Fixed prerelease update ordering with SemVer so `gp.10` sorts after `gp.9`.
[2026-07-25] Fixed local release-manifest generation to derive the repository URL from the fork's package metadata when no explicit argument or Actions repository is present. Added an invariant test covering every generated URL.
[2026-07-25] Replaced the fork README's upstream npm installation commands with the supported Good Place desktop release and source-checkout paths, including a prominent fork notice.
[2026-07-25] Centralized the fork product name, bundle ID, update repository, Squirrel name, and default data-directory name in `distribution.json`; Electron, Forge, runtime configuration, release generation, fallback manifests, and macOS packaging validation now consume it.
[2026-07-25] Split fork-only history into `FORK_PROGRESS.md`, kept `PROGRESS.md` for upstream-compatible work, documented the upstream mirror and branch model, and added a guarded upstream-sync helper.
[2026-07-25] Moved workspace synchronization into the Electron app instead of executing a workspace-owned script.
